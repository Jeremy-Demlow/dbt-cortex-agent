# Code of Conduct

Be respectful, constructive, inclusive, evidence-driven, and protective of privacy. Harassment,
discrimination, threats, doxxing, sexualized conduct, sustained disruption, and disclosure of
confidential information are unacceptable.

This applies in package spaces and when representing the project. Send sanitized conduct reports
privately to `jeremy.demlow@snowflake.com`. Final enforcement requires two-maintainer approval
and is blocked while the second role is vacant, except for temporary protective action by the
repository host. Possible actions include warning, content removal, restriction, or ban.

This is an independent project process, not a Snowflake HR, ethics, support, or employee channel.
